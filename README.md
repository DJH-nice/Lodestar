## 是什么

Lodestar 是一款 macOS / Apple Silicon 原生的文件搜索工具。

- **随时能叫醒** —— 菜单栏常驻图标，`⌥⌘Space`（可改）一键唤起
- **输入即搜** —— 打字的同时就在搜，命中词直接高亮
- **搜得到一切** —— 文件名、路径、扩展名、大小、修改时间
- **跟得上磁盘** —— 文件一变，索引跟着更新
- **插上 U 盘就能搜** —— 外接盘自动进索引，拔掉就移除

界面是 Vue 3 写的，引擎是 Rust 写的 —— 整个应用**没有一个第三方搜索引擎的代码**。

## 安装

从 [Releases](https://github.com/YOUR_ACCOUNT/lodestar/releases) 下载 `Lodestar.dmg`，
双击挂载后把 `Lodestar.app` 拖进「应用程序」。

> 首次打开如果 macOS 说「无法验证开发者」——
> 对着 `Lodestar.app` **右键 → 打开** → 再点「打开」。
> （这个包没有付费的 Apple 开发者证书，只能 ad-hoc 签名。）

装好后建议先做两件事：

1. **打开菜单栏图标 → 设置 → 选要索引的目录**（默认是整个家目录 `$HOME`）
2. **设置 → 索引 → 点「应用并重建索引」** —— 第一次扫描会花几秒

| 操作 | 怎么做 |
|---|---|
| 唤起窗口 | `⌥⌘Space`（可在设置里改） |

| 在访达中定位 | 右键结果行 → 在访达中显示 |
| 用别的应用打开 | 右键结果行 → 打开方式 |

搜索框支持 `AND` / `OR` / `NOT` 与括号，可以组合多个条件。

## 查询语法

速查表（`⌘/`）里有全部写法，这里是最常用的几条：

| 想做什么 | 这么写 |
|---|---|
| 按名字找 | `报告` |
| 按后缀找 | `ext:pdf`（多个用分号：`ext:pdf;doc;xlsx`） |
| 找大文件 | `size:>10M`（十进制，1M = 1 000 000） |
| 在某个目录里找 | `path:Documents` |
| 今天改过的文件 | `dm:today` |
| 最近三天改过的 | `dm:past3days` |
| 精确匹配文件名 | `exact:alpha.txt` |
| 区分大小写 | `case:ALPHA` |
| 正则 | `regex:"^gam"` |
| 精确短语 | `"my file.txt"` |
| 排除某种文件 | `NOT ext:png` |
| 组合 | `(alpha OR beta) AND txt` |

**大小写**：默认不区分（搜「报告」能搜到「Report.pdf」）。
但查询里**带大写字母就自动区分**（搜「Report」不会命中「report.pdf」）——
这条叫 smart case。

**通配符**：`*` 匹配任意多个字符，`?` 匹配一个。`*` 单独用就是「匹配全部」。

## 索引与性能

索引的是你选中的目录（默认 `$HOME`）。有几件事值得知道：

- **排除规则默认生效**：`~/Library`、`/Applications`、`target/`、`node_modules/`
  与隐藏目录**整棵不进索引**。这很重要 —— `~/Library` 一个目录就有 26 万个条目。
- **索引会落盘**：第二次启动直接读档，**不用重新扫盘**。
- **实时更新**：文件变了会自动更新索引（可以关掉，尤其索引整个家目录时）。
- **索引档按目录分文件**：家目录一个档、外接盘各一个档 ——
  插拔 U 盘**不会**把家目录的档作废（以前会 → 每次插拔都全量重扫）。

### 外接盘（U 盘 / 移动硬盘）

macOS 把外接盘挂在 `/Volumes/<卷名>`。Lodestar 会**自动发现并索引**它们：

- **插上就进索引** —— 一秒内发现并扫描完，状态栏显示「U盘 · 正在索引…」
- **拔掉就移除** —— 条目立刻消失（不会留着让你搜到已经拔掉的盘）
- **插回来能立刻搜** —— 上次的索引还在，先秒开，再后台刷新一遍
- **只索引本地磁盘** —— 网络共享（smbfs / nfs）不会被自动索引

> 换索引目录时，已经插着的盘**不会被踢出索引**；
> 但如果你填了一个**不存在**的目录，会明确报错（不会悄悄改成索引 U 盘）。

### 实测数字（2026-10-25，Apple Silicon）

| 指标 | 数值 |
|---|---|
| 冷启动读索引档 | **3.8 ms**（8,993 项） |
| 全量扫描家目录 | **109 ms**（8,585 项，热缓存） |
| 查询延迟 | `*` 0.40 ms · 普通词 0.32 ms · `ext:pdf` 0.06 ms |
| 索引落盘 | 10.5 ms（3.2 MB，含 fsync） |
| 增量更新 | 改 1 个文件 **0.01 ms** · 改 100 个文件 **0.38 ms**（一次更新） |
| 后台常驻 CPU | **0.10%**（菜单栏常驻、窗口隐藏时） |
| 外接卷监控 | 每秒一次 `getfsstat` → **6.7 µs**（可忽略） |

> 这些数字是**同机同树交替 A/B** 测出来的（基线版本 vs 当前版本轮流测）——
> 单次测量在这台机器上噪声能到 4 倍，绝对值会随机器状态漂移。

## 隐私

Lodestar **不联网**。没有遥测、没有崩溃上报、没有更新检查。
索引只存在你自己的机器上（`~/Library/Application Support/com.lodestar.macos/`）。

## 开发

```bash
# 前端
cd app && pnpm install && pnpm dev

# 引擎单测（不依赖 Tauri，可单独跑）
cd app/src-tauri && cargo test -p search-core

# 全部 Rust 测试（249 项，含 31 个护栏集成测试）
cd app/src-tauri && cargo test

# 前端单测（278 项）
cd app && pnpm vitest run

# 打包（唯一入口，带自检）
bash app/scripts/bundle-app.sh
```

### 架构

```
app/src/                  Vue 3 前端（虚拟滚动、语法高亮、预览卡…）
app/src-tauri/src/        Tauri 后端
                          volumes  外接卷枚举 + 监控线程（新增）
                          watcher  FSEvents 监控 + 增量更新
                          commands IPC 命令
                          settings 设置 + 引擎生命周期
                          lifecycle 窗口可见性 / 空闲判定
app/src-tauri/search-core/ ★ 自研搜索引擎内核
                          scan       并行遍历 + 排除剪枝
                          store      索引落盘（每根一个文件）
                          query      查询语法（词法 / 语法 / 匹配）
                          fold       Unicode 折叠（索引期做一次）
                          engine     索引 / 排序 / 分页 / 高亮
                          incremental 增量更新（脏路径 → 就地改索引）
                          exclude    排除规则（唯一真相）
                          syntax     语法表（唯一真相）
                          worker     串行搜索线程
```

`search-core` **不依赖 Tauri** —— 这是刻意的：引擎必须能独立测试。
